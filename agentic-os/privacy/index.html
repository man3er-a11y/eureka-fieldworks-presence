Agentic OS Privacy Policy

Last updated: November 12, 2026

Agentic OS is a personal tool used only by its owner. It is not available to the public.

What it accesses

When the owner signs in with Google, Agentic OS reads email messages, labels and calendar events from the owner's own Google account so they can be shown in the owner's private dashboard.

How data is used

Google data is used only to display and organise the owner's own email and calendar inside Agentic OS. It is not sold, shared with third parties, or used for advertising.

Storage

Data is stored only on the owner's own computer. Sign-in tokens are kept locally and can be removed at any time by disconnecting the account in Agentic OS or at myaccount.google.com/permissions.

Google API compliance

Agentic OS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
